# LRY Fintech Advisory Platform 🚀
**Where Smart Money Meets Smart Advice**

Welcome to the official repository for the LRY Fintech Advisory platform. This project transforms a standard financial brochure website into a high-converting **Digital Wealth Advisory Platform and Lead Generation Engine**.

Designed specifically for modern wealth management, it captures social media traffic (Instagram, WhatsApp) and converts visitors into qualified financial planning leads through interactive calculators, risk profiling, and seamless consultation booking.

---

## 🎯 The Primary Lead Generation Funnel
This platform is built around a highly optimized Conversion Rate Optimization (CRO) funnel:

1. **Traffic Source:** Instagram Reel / Social Media 
2. **Action:** User comments "PLAN" -> Receives DM with website link
3. **Engagement:** User lands on website -> Selects Financial Goal (e.g., Child Education, Retirement)
4. **Interactive Profiling:** User completes Risk Profile Assessment & uses Smart Calculators
5. **Lead Capture:** User enters details to generate a Personalized Financial Report
6. **Conversion:** Automatic redirect to WhatsApp for discussion -> Books Google Calendar Consultation
7. **Result:** Client Onboarding

---

## ✨ Core Features
* **Smart Goal Planners:** Interactive calculators for SIP, Child Education, Retirement, and Marriage planning.
* **Dynamic Visualizations:** Integrated `Chart.js` for real-time visual feedback on asset growth and inflation impact.
* **Risk Profile Assessment:** Engine to categorize users (Conservative to Aggressive) and suggest asset allocations.
* **Frictionless Lead Capture:** LocalStorage-backed lead capture form that seamlessly hands off to WhatsApp.
* **Integrated Booking:** Native Google Calendar integration for zero-friction consultation scheduling.
* **Mobile-First UX:** Sticky bottom navigation for mobile users to drive immediate WhatsApp chats and call bookings.

---

## 🛠️ Technical Stack
This project is engineered to be extremely lightweight, fast-loading, and easily maintainable without the overhead of heavy JavaScript frameworks.

* **Frontend Structure:** HTML5
* **Styling:** CSS3 (Custom variables mapped to LRY Brand Identity)
* **Interactivity & Logic:** Vanilla JavaScript (ES6)
* **Data Visualization:** [Chart.js](https://www.chartjs.org/) (via CDN)
* **Booking Integration:** Google Calendar Scheduling API
* **Icons:** FontAwesome 6
